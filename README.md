## Higher Lower Game 🎮

A fun console-based Higher Lower game built using Python. Players compare two famous personalities and guess who has more social media followers. The game continues as long as the player keeps guessing correctly, while the score increases after every correct answer.



## Features
Random celebrity comparison system
Score tracking
Continuous gameplay until wrong guess
Simple console-based interface
Uses real-world inspired follower counts
Beginner-friendly Python project



## Technologies Used
Python 3
random module



## How to Play
Two personalities are displayed.
Guess who has more followers by typing:
A
B
Correct guesses increase your score.
Wrong guesses end the game.



## How to Run
Install Python on your system.

Save the file as main.py



## Run the program:

python main.py

## Game Logic
Random accounts are selected from the dataset.
User guesses which account has more followers.
The score increases for every correct answer.
The game ends after an incorrect guess.
